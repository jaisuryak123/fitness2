# MuscleGainTracker

Backend and shared foundation of an offline Android muscle-gain tracker (Kotlin, Room, Flow, DataStore).

- Open the folder in Android Studio (JDK 17). Gradle wrapper 8.9 is included.
- Run tests: `./gradlew test`
- Documentation: `docs/` (start with `AI_HANDOFF.md`, then `INTEGRATION_CONTRACT.md`)
- The UI is intentionally absent; `:app` is only a shell for the Compose frontend.
