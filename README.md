# fitness_app

Personal Muscle Gain Fitness Tracker Android application.
Built with Kotlin, Jetpack Compose, Material 3, MVVM architecture, Room SQLite local database, and offline-first design.

## Features
- **Today Dashboard**: Real-time calorie and macro target tracking, scheduled workout display, quick actions, body weight logging.
- **Nutrition Logging**: Manual entry for meals/snacks with macro-calorie mismatch validation.
- **Workout Tracking**: Gym (exercise sets/reps/weight builder), Running (pace & speed preview), Walking, Other Cardio with real-time MET calorie expenditure estimates.
- **Training Plan & Attendance**: 7-day schedule with gym, running, and rest day management.
- **Weekly Progress**: 7-day bar charts for calories and protein, weight trendline, and workout adherence KPIs.
- **History Log**: 14-day interactive calendar strip to review and edit past records.
- **Profile & Targets**: Editable physical metrics, daily nutrition targets, weight measurement history, and supplement tracker.
- **Scheduled Reminders**: WorkManager-based local reminders for meals, workouts, weights, and supplements.
- **Data Export**: Full JSON backup and CSV spreadsheets export.
